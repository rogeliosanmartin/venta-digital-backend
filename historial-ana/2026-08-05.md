# ANA — 2026-08-05 — Backend Venta Digital

## Objetivo del día

Montar NestJS con TypeORM sobre BD beta, auth dual (vendedor PIN WhatsApp / monitor-admin + refresh) y administración de usuarios con permisos default.

## Hecho

- `.env` con `PORT=3022`, JWT, WhatsApp NIP, credenciales DB beta, admin semilla.
- Entidades `vd_users`, `vd_permissions`, `vd_user_permissions`, `vd_refresh_tokens` (UTC `timestamptz`).
- Auth:
  - Vendedor: solicitar/verificar PIN (flujo tipo `api-recibodigital-nest`) + JWT hasta fin del día (`BUSINESS_TIMEZONE`).
  - Monitor/Admin: login bcrypt + access/refresh con rotación.
- Users: alta por ADMIN con permisos default por tipo; seed de catálogo de permisos y admin inicial.
- Sales:
  - `GET /api/sales/mias` → ventas propias (VENDEDOR)
  - `GET /api/sales/todas` → todas las ventas de vendedores (MONITOR/ADMIN + `ventas.ver`)
- `AGENT.md` + este historial ANA.

## Decisiones

- Prefijo `vd_` para convivir con Odoo en `odoo-gsm` sin tocar sus tablas.
- Passwords con bcrypt (mejora vs MD5 del sistema de referencia).
- Vendedor no tiene refresh; monitor/admin sí.
- `DB_SYNC=true` en beta para crear tablas propias.

## Pendiente / siguiente

- Modelo real de ventas/transacciones.
- Migraciones formales y apagar sync en ambientes controlados.
- Hardening de rate-limit en endpoints de PIN.
