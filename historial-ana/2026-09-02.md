# ANA — 2026-09-02 — Jefe de ventas en usuario vendedor

## Cambio

Columna `users.nombre_jefe_ventas`. Solo aplica a tipo VENDEDOR.

Al guardar o finalizar una venta (y al registrar pago) el API copia ese
nombre a `sale.nombre_jefe_ventas` para la carátula.

Reiniciar Nest con `DB_SYNC=true` para crear la columna.
